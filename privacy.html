Privacy Policy

Last updated: 18 October 2026

1. Overview

Sevenstones Rclone Backup is a private, non-commercial backup application operated by an individual for personal use.

2. Google data accessed

The application requests read-only access to Google Drive using the Google Drive API and OAuth 2.0.

This access permits listing, reading and downloading files and associated metadata for backup purposes.

3. How data is used

Google Drive data is used solely to create, maintain and verify local backup copies and to support recovery of personal files.

Google Drive data is not used for advertising, profiling, commercial analytics or AI training.

4. Data storage and security

Downloaded files are stored on systems controlled by the account owner.

OAuth credentials and access tokens are stored locally in the rclone configuration and are not included in this public website or its source repository.

Access to backup storage is restricted through locally managed system permissions. Operational logs may contain file paths, names and transfer diagnostics.

5. Data sharing

Google Drive contents are not sold, published or transferred to third parties for commercial purposes.

The backup process communicates with Google to access the authorised account and transfers data to the owner's local storage.

This informational website is hosted by GitHub Pages. Google Drive files and authentication tokens are not transmitted to this website.

6. Retention and deletion

The account owner controls the retention, deletion and restoration of locally stored backups.

Google account access can be revoked through the owner's Google Account permissions. Revoking access prevents further authorised API access but does not automatically remove existing local backup copies.

7. Website information

This website uses no custom analytics, advertising, tracking scripts or cookies. GitHub may process technical access information as part of hosting GitHub Pages.

8. Changes

This policy will be updated if the application's data access or handling practices change.

9. Contact

Questions about this application may be directed to its owner through the associated GitHub profile .
