Sevenstones Rclone Backup

Sevenstones Rclone Backup is a private, single-user data backup solution operated on a personal self-hosted server.

Purpose

The application uses rclone and the Google Drive API to create and maintain local backup copies of the owner's Google Drive files.

How it works

Google OAuth 2.0 authorisation provides read-only access to the owner's Google Drive. Files are downloaded directly to locally controlled storage for backup and recovery purposes.

Privacy and security

The application is intended exclusively for personal use. It does not provide a public file-sharing service, sell personal information, or use Google Drive data for advertising.

OAuth credentials and downloaded files remain on the owner's systems and are not published through this website.
